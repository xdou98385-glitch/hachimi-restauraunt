# 哈基米餐厅 🐈

一家可以撸猫的小餐厅，休闲经营游戏。

- **在线**：客人从门口走进来坐下，头上冒出想吃的菜 → 你点灶台下锅 → 火苗冒烟几秒 → 菜到出餐台 → 点客人上菜收钱。没有"一天"，也没有结算界面。
- **画面**：现在没有贴图，每样东西是带字的色块（橘猫就是写着"橘猫"的橘色小猫头）。
- **离线**：客人回家，店里靠猫和自动设备往招财罐里攒钱（默认最多攒 12 小时），回来点一下收走。
- **照顾猫**：喂猫粮/罐头、摸摸、换猫砂、喷除臭剂。买自动猫粮机、自动猫砂盆之类的设备能少操心，离线也照顾得到。
- **流浪猫**：摆了对的家具（纸箱、猫垫子、猫抓板……），流浪猫会自己找上门，可以收养。
- **不会倒闭**：没照顾好，最多是猫蔫了、赚得少。

## 目录

```
core/            纯逻辑，不碰界面（网页、小程序、AI 伴侣的服务器都用这一份）
  data/          所有内容和数值都在这里，全是 JSON
    cats.json        猫的品种
    dishes.json      菜（用什么食材、做几秒、卖多少、学要多少钱）
    ingredients.json 食材
    supplies.json    消耗品（猫粮、罐头、猫砂、除臭剂）
    devices.json     设备（自动猫粮机、灶台……）
    furniture.json   家具（座位、人气、舒适度、吸引哪种猫）
    balance.json     数值平衡（客人多久来一位、卫生掉多快、离线攒多少……）
  src/           规则代码
  test/          测试
web/             普通版网页（存档放在浏览器本地）
miniprogram/     微信小程序（还没做）
```

存档就是一个 JSON（网页里「日志 → 导出存档」能看到）。

## 在自己电脑上跑

**第 1 步：确认装了 Node.js**（22.18 或更新）

```bash
node -v
```

成功：显示 `v22.18.0` 或更大的数字（比如 `v24.x`）。
失败（`command not found` 或版本太旧）：去 https://nodejs.org 下载 LTS 版安装，装完关掉终端重新打开，再试一次。

**第 2 步：下载代码、安装依赖**

```bash
cd ~ && git clone https://github.com/xdou98385-glitch/hachimi-restaurant.git && cd hachimi-restaurant && npm install
```

成功：最后几行是 `added ... packages`，没有红色的 `ERR!`。
失败：如果 git 要你登录，按提示用浏览器登录 GitHub（这是私有仓库）。

**第 3 步：开始玩**

```bash
npm run dev
```

成功：看到 `打开浏览器访问 http://localhost:8000`，用浏览器打开这个地址就能玩。按 `Ctrl+C` 停止。

**想要单文件版**（发给别人或者双击就玩）：

```bash
npm run build
```

成功：最后一行是 `单文件版：web/dist/hachimi.html`，双击这个文件就能玩。

## 改内容

想加一只猫、一道菜、一件家具：照着对应 JSON 里已有的条目复制一份改。改完运行：

```bash
npm test
```

成功：最后显示 `# fail 0`。
失败：会写明哪个 id 写错了，比如 `菜「鱼汤」用到的食材「fsh」不存在`。
